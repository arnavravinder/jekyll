# Welcome to Obsidian

Obsidian is a sleek, dark grey theme with vibrant colored accents designed for Jekyll-powered blogs, documentation sites, and resource hubs.

## Features

- Dark grey color scheme with customizable accent colors
- Responsive design for all devices
- Clean typography optimized for readability
- Built-in code highlighting
- Seamless GitHub Pages integration
